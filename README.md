# Platform Skills

Общие навыки Sangrita Tech для работы с текстами и историей изменений.

## Навыки

- [Единый стиль текста](skills/plain-text-style/SKILL.md) задаёт простой язык, правила знаков, заголовков и списков.
- [Обновление changelog](skills/update-changelog/SKILL.md) собирает подтверждённые изменения в короткий список с датой и версией.

## Использование

Помести папку нужного навыка из skills в свою папку навыков. Для update-changelog также установи plain-text-style. Папки должны лежать рядом.

В запросе можно указать точное имя навыка.

```text
Используй $plain-text-style, чтобы отредактировать описание игры.
Используй $update-changelog, чтобы обновить changelog.
```

Общие правила хранятся здесь. Игровые сценарии и очередь публикаций находятся в репозитории [Wardrones DC Docs](https://github.com/sangrita-tech/wardronesdc-docs).
